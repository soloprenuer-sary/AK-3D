# Sub-category pictures

30 flat illustrations in the brand colours, one per sub-category, 1200 x 900 px.

- `png/` is what you upload. WordPress accepts PNG and JPG (it blocks SVG by default).
- `svg/` are the editable sources.

File name = main category, an underscore, then the sub-category. Upload each one as the **Thumbnail image** of the matching child category in WooCommerce (Products > Categories > edit the sub-category). For example `home-decor_lamps.png` goes on Lamps under Home decor.

"Busts" exists under Figurines & miniatures and under Original characters, so each has its own file. Upload the right one to the right parent.
